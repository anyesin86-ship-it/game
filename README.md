# Galaxy Arcade

A lightweight, Poki-style landing page that bundles three playable HTML games built with vanilla HTML, CSS, and JavaScript.

## Games
- **Astro Dodger** – Keyboard-driven endless dodging game.
- **Memory Flip** – Match pairs before the timer ends.
- **Paddle Blast** – Breakout-inspired paddle and brick challenge.

## Running locally
Use any static file server. For example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
