# Arcade Galaxy

GitHub Pages에 바로 배포할 수 있는 작은 HTML5 게임 포털입니다. `index.html`로 메인 허브가 제공되고, 세 가지 게임이 `/games` 폴더에 포함되어 있습니다.

## 포함된 게임
- **Asteroid Dodger**: 방향키로 운석을 피해 점수를 올리는 캔버스 액션.
- **Memory Match**: 같은 이모지를 짝지어 찾는 퍼즐.
- **Neon Runner**: 점프하며 장애물을 넘는 사이드 러너.

## 사용 방법
1. 이 저장소를 그대로 GitHub에 올리고 GitHub Pages를 활성화하세요.
2. 메인 주소로 접속하면 `index.html`에서 게임 목록을 확인할 수 있습니다.
3. 각 게임 페이지는 모바일/데스크톱 모두 대응합니다.

별도 빌드 과정 없이 정적 파일 그대로 배포할 수 있습니다.
